# Retest pe iPhone — planificator flexibil

*Pentru fondator, după: backup verificat → migrație aprobată → postflight reușit → push aprobat → build
Preview gata. Adresa: `https://diversibebe-git-release-v2-rc-velicofs-projects.vercel.app/v2`
(autentificare Vercel + codul de invitație). Durată: ~15 min.*

Înainte de start: închide fila veche și deschide adresa din nou (sau trage în jos pentru reîncărcare),
ca să rulezi build-ul nou. În Profil, jos, „build …” trebuie să arate commitul nou.

## 1. Trei mese pe zi
- [ ] Plan → **Pentru câte zile?** 3 zile · **Ce mese?** Mic dejun + Prânz + Cină → „Arată planul”.
- [ ] Apar 3 zile × 3 mese, fiecare cu eticheta mesei (MIC DEJUN / PRÂNZ / CINĂ).
- [ ] Mesele implicite pentru Eduard corespund etapei lui (6 luni: doar prânz; 8+ luni: trei mese); gustarea nu e bifată.

## 2. Înlocuire
- [ ] În propunere: „Altă rețetă” pe o masă → se schimbă doar acea masă, de același tip.
- [ ] „Scoate” pe o masă → dispare doar ea. „Salvează planul” → mesaj cu numărul de mese și zile.
- [ ] În planul salvat: ↻ pe o masă → altă rețetă de același tip; × pe alta → dispare; „+ Cină” pe o zi fără cină → se adaugă.

## 3. Cumpărături
- [ ] „De cumpărat” după salvare: listă cu cantități adunate (ex. „250 g”), nu dubluri pentru același ingredient.
- [ ] După o înlocuire sau o eliminare, lista se schimbă.
- [ ] „Am acasă” pe un produs → trece la „Ai deja acasă”; bifele rămân după reîncărcare.

## 4. Alergii (contul tău: reacție înregistrată în V1 la „Piure de banană & avocado”)
- [ ] Profil → alergia apare ca „rețetă: banana, avocado, lapte”.
- [ ] Nicio masă din plan nu are marcajul „Conține un alergen declarat”.
- [ ] Descoperă: o rețetă cu banană/avocado/lactate are marcaj și nu se poate adăuga în plan.
- [ ] Dacă unele mese rămân libere, mesajul spune, pe tip de masă, de ce.

## 5. Salvare și reconectare
- [ ] Reîncarcă pagina: planul și alegerile (zile, mese) sunt aceleași.
- [ ] Cont → Deconectare → conectare din nou (Google): același plan, aceleași mese.
- [ ] Azi: „Mesele de azi” cu „Am pregătit” → butonul devine „Pregătită”.
- [ ] (Opțional) Mod avion → „Salvează planul” → mesaj „Salvarea nu a reușit”; fără mod avion → „Reîncearcă” → salvat.

## 6. Doi copii
- [ ] Cont → creează un al doilea profil (etapă diferită).
- [ ] Plan → „Pentru”: al doilea copil → plan gol, mesele implicite ale etapei lui.
- [ ] Fă un plan cu alte mese/zile pentru el; revino la Eduard → planul și alegerile lui sunt neschimbate.
- [ ] Alergia „pentru tot contul” se aplică ambilor copii până o asociezi explicit unuia (Profil).

## 7. V1 neatins
- [ ] diversibebe.ro (V1): jurnal, alergii, plan V1 funcționează ca înainte; alergia apare neschimbată.
